## Documentation Scripts

The following scripts are available for managing the documentation using VitePress:

- **`docs:dev`**: Starts a local development server for the documentation.
    ```bash
    npm run docs:dev
    ```
    Or with yarn:
    ```bash
    yarn docs:dev
    ```

- **`docs:build`**: Builds the documentation for production.
    ```bash
    npm run docs:build
    ```
    Or with yarn:
    ```bash
    yarn docs:build
    ```

- **`docs:preview`**: Previews the production build of the documentation.
    ```bash
    npm run docs:preview
    ```
    Or with yarn:
    ```bash
    yarn docs:preview
    ```
