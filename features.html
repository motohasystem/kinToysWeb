機能

kinToys に入っている「おもちゃ」たちを紹介します。

ポップアップからコピー

ツールバーの kinToys アイコンから開くポップアップで、表示中の画面のデータをまとめてコピーします。

01

テーブルをコピー

一覧画面に表示中のテーブルを CSV / TSV などでコピー。TSV ならそのまま Excel に貼り付けられます。

一覧画面
02

フィールド・レコードをコピー

一覧画面から特定のフィールドだけ、またはレコード単位でコピーできます。

一覧画面
03

CSV / TSV / JSON でコピー

詳細画面のレコードを CSV / TSV や JSON 形式でクリップボードへ。

詳細画面
04

テンプレートに流し込んでコピー

自作のテンプレートにフィールド値を埋め込み、メール文面や JSON などの定型文を作れます。

一覧・詳細画面
05

サブテーブルに CSV を貼り付け

クリップボードの CSV を、編集画面のサブテーブルへまとめて流し込みます(オプションで有効化)。

編集画面

画面クリックでコピー

ポップアップを開かなくても、画面をクリックするだけでコピーできます。

06

フィールドをコピー

一覧画面・詳細画面でフィールドの値をクリックしてコピーします。

一覧・詳細画面
07

レコードの表示・全体をコピー

一覧画面の行から、表示されている内容またはレコード全体をコピーします。

一覧画面
08

URL リンクをコピー

レコードへの URL リンクをコピーして、チャットやメールにすぐ貼れます。

一覧画面

コンテキストメニュー

右クリックメニューからも機能を呼び出せます。

09

シンプルな URL をコピー

余計なパラメータを省いた、すっきりしたレコード URL をコピーします。

右クリック
10

一覧画面の改行表示をトグル

一覧画面で文字列フィールドの改行表示を切り替えます。

右クリック

アプリ設定・プラグイン設定

アプリを作る人、管理する人のための機能です。

11

フィールド設定をコピペ

フォーム編集画面のフィールド設定ダイアログを JSON でコピー&ペースト。文字列・数値・計算・日時・ドロップダウン・ユーザー選択・関連レコード一覧・ルックアップなど多くのフィールドに対応します。

アプリ設定
12

絞り込み・ソート条件をコピペ

一覧の絞り込みダイアログで、絞り込み条件とソート条件を JSON でコピー&ペーストできます。

一覧の絞り込み
13

プラグイン設定ファイルの保存

プラグイン設定画面で、設定ファイルをダウンロード / アップロードできます。

プラグイン設定

オプションとその他

オプション画面で、好みに合わせて動作を調整できます。

14

画像コピーボタン

ポップアップからグラブコピーしたテキストを、画像としてクリップボードにコピーできます。

オプション
15

文字列の改行表示

一覧画面・詳細画面で、一行文字列と複数行文字列を改行表示します。

オプション
16

無効モード

ポップアップ右上のラジオボタンから、kinToys の機能を一時的に停止できます。

ポップアップ
17

多言語対応

日本語・英語・中国語(簡体/繁体)・スペイン語・ポルトガル語・タイ語・ベトナム語に対応しています。

オプション
