クリップボードで
kintone を便利に。

kinToys は、kintone のデータをいろいろな角度からクリップボードに取り出す、遊び心のあるブラウザ拡張です。一覧・詳細・設定画面のちょっとした「めんどう」を、小さな「おもちゃ」たちが片付けます。

kinToys でできること

kintone から外へ、外から kintone へ。コピペでつなぐための機能をまとめました。

k

ポップアップから一括コピー

一覧のテーブルやレコードを CSV / TSV / JSON / YAML でコピー。TSV ならそのまま Excel に貼り付けられます。

^

画面クリックでコピー

一覧や詳細画面でフィールドをクリックするだけで値をコピー。レコードの URL もすぐ取り出せます。

C

テンプレートで定型文

自作のテンプレートにフィールド値を埋め込んで、メール文面や JSON などの定型文を作れます。

⚙

フィールド設定をコピペ

アプリ設定画面のフィールド設定や、一覧の絞り込み・ソート条件を JSON でコピー&ペースト。

⇅

サブテーブルへ貼り付け

クリップボードの CSV を、編集画面のサブテーブルにまとめて流し込めます。

⇩

プラグイン設定の保存

プラグイン設定画面で、設定ファイルをダウンロード / アップロードできます。

はじめかた

インストールは 1 分で完了します。

  1. Chrome ウェブストアから追加

    「Chrome に追加」ボタンを押して拡張機能をインストールします。

  2. ツールバーにピン留め

    パズルアイコンから kinToys をピン留めすると、すぐに呼び出せます。

  3. kintone を開いてアイコンをクリック

    一覧や詳細画面でアイコンを押すとポップアップが開き、コピー方法を選べます。
