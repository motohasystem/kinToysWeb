# 主な使い方

kinToysは二通りのコピー方法があります。ひとつはポップアップからのコピーと、もうひとつは画面クリックによるコピーです。

### ポップアップからCSV/TSVでコピペ

ブラウザのタスクトレイにあるアイコンをクリックで表示されるポップアップウィンドウから行うコピー捜査について紹介します。

![](./img/popup_0_4_3.png)

- 一覧画面で
    - テーブルをコピー
    - フィールドをコピー
    - レコードをコピー
    - テンプレートに流し込んでコピー

- 詳細画面で
    - CSV/TSVをコピー
    - JSONをコピー
    - テンプレートに流し込んでコピー


### 画面クリックでコピペ

- 一覧画面をクリックして
	- フィールドをコピー
	- レコードの表示をコピー
	- レコードの全体をコピー
	- URLリンクをコピー

### コンテキストメニューからコピペ
- シンプルなURLをコピー
- 一覧画面の改行表示をトグル

### アプリ設定画面でコピペ
- フィールド設定ダイアログのコピペ

### プラグイン設定画面でコピペ
- プラグイン設定ファイルのダウンロード
- プラグイン設定ファイルのアップロード


## 無効モード

![](img/button_enabled.png)

一時的に機能を停止させることができます。

ポップアップの右上に表示されているラジオボタンから切り替えてください。

無効化状態では、下のスクリーンショットのようにラジオボタンに網掛けが入ります。

![](img/popup_disabled.png)
