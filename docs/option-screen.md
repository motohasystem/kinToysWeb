# オプション画面

Chrome拡張機能としての設定画面について解説します。

拡張機能トレイのアイコンを右クリックして「オプション」を選ぶか、ポップアップにあるoptionsリンクからオプション画面を開きます。

## テンプレート設定

ポップアップのラジオボタンをtemplateにしているときに、グラブコピーで適用するテンプレートを作成します。

書き方については[テンプレート記法](template-examples.md)を参照してください。

## オプション設定

### [ ] Enable image copy button 

有効にすると、ポップアップからグラブコピーした際にクリップボードに画像としてテキストをコピーします。

(ver.0.4.2 以降)

### [ ] Break multi-line and single-line text (list view)

有効にすると、一覧画面で一行文字列と複数行文字列を改行表示するようになります。

(ver.0.4.3 以降)
